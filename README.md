# Distance Calculator

## Description
This program calculates the distance between two points on a 2D coordinate plane using the distance formula.

## How to Run the Program
Run the Python file and enter the x and y coordinates when prompted.

## Input Needed
- x1
- y1
- x2
- y2

## Sample Output
Enter x1: 1
Enter y1: 2
Enter x2: 4
Enter y2: 6

The distance between the two points is: 5.00
